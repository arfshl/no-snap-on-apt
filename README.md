# NoSnap
Script for removing snap completely and adding proper firefox and thunderbird .deb repo just for 1 click

[Get Chromium Here](https://download-chromium.appspot.com/) if you want to use it

### Setup
    curl -fssL https://github.com/arfshl/no-snap-on-apt/raw/main/nosnap.sh | bash
### Undo Setup
    curl -fssL https://github.com/arfshl/no-snap-on-apt/raw/main/remove.sh | bash
